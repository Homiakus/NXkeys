🎯 Главный принцип NXKeys v8

Короткая мнемоническая команда запускает намерение (semantic operation), а NXKeys автоматически определяет контекст активной детали NX, анализирует предварительный выбор, включает корректный Selection Intent и управляет коллекторами ввода.

Level A — Direct Keys

Одноклавишный доступ

Выполнение сверхчастых команд без вызова Leader (`S` — Sketch, `X` — Extrude, `B` — Blend, `C` — Chamfer, `Space` — Hide, `Esc` — Smart Cancel).

Level B — Selection Intent

Модификаторы коллекторов

Клавиши `1–4` изменяют правила выбора ребер/граней/тел в активном коллекторе геометрии (Single, Tangent, Connected, Feature/Boundary).

Level C — Leader HUD

Мнемонические пути CapsLock

2–3 мнемонических токена для доступа к полному спектру функций NX (например, `F C` — Chamfer, `S L` — Line, `M D` — Drafting).

Workspaces — Пространства

Постоянный контекст HUD

Рабочие пространства (`M L` Layer, `M W` WAVE, `V G` Display), которые не закрываются после выполнения единичного действия.

Мнемонические последовательности CapsLock (Level C). Нажмите на карточку для просмотра деталей контракта.
Прямые клавиши Level A (работают мгновенно при фокусе в графическом окне NX).

M → L Layer Workspace

Управление рабочим слоем, видимостью слоев, категорий и переносом объектов между слоями.

M → W WAVE Workspace

Создание, проверка, обновление и обслуживание междетальных геодезических связей WAVE в сборке.

V → G Geometry Display Workspace

Изоляция, скрытие, отображение по типам объектов, пресеты стиля отображения и разрезные плоскости.
