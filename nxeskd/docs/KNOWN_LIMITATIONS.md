# Известные ограничения версии 1.0.0

1. Бинарники необходимо собрать локально против установленной NX 2512.
2. Точные builder-свойства проверяются диагностикой API; неподтвержденная операция не считается успешно выполненной.
3. Полностью автоматическое определение главного вида, баз, допусков и шероховатости невозможно без инженерной семантики модели.
4. Для надежного PMI нужны модельные виды, группы и ассоциативные объекты.
5. Рамки и сложные штампы должны находиться в PRT-шаблонах.
6. Автоматическая раскладка PMI сначала вызывает штатный метод NX, если он доступен; иначе создается `MANUAL_REVIEW`.
7. Создание Flat Pattern без заранее указанной стационарной грани требует ручной проверки.
8. Состав колонок Parts List конфигурируется, но конкретное оформление зависит от шаблона и лицензии Drafting.
