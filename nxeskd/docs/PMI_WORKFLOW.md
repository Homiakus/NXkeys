# Подготовка PMI для автоматического чертежа

## Модельные виды

Создайте устойчивые виды:

```text
DWG_FRONT
DWG_TOP
DWG_RIGHT
DWG_ISO
```

PMI должен лежать в плоскости соответствующего модельного вида и быть связан с геометрией.

## Группы

```text
DRAWING_FRONT
DRAWING_TOP
DRAWING_RIGHT
DRAWING_ISO
MANUFACTURING
INSPECTION
REFERENCE_ONLY
HIDDEN
```

В задании можно напрямую сопоставить группу виду:

```json
"groupToView": {
  "DRAWING_FRONT": "VIEW_FRONT",
  "FLAT_PATTERN": "VIEW_FLAT_PATTERN"
}
```

## Приоритет разрешения

1. Явное сопоставление вида.
2. Ассоциированный модельный вид PMI.
3. Группа PMI.
4. Ближайшая ориентация.
5. Главный вид с предупреждением.

## Дубликаты

Сравнение выполняется по источнику, persistent name, семантической подписи и managed id. При наличии одного размера на нескольких видах выбирается вид с истинной формой и меньшим числом пересечений.

## Развертка

Для листового металла используются группы:

```text
FLAT_PATTERN
LASER_CUT
BENDING
MANUFACTURING
```

Настройка `inheritFlatPatternPmi=true` должна быть активна до размещения вида. Профиль разрешает пересоздать управляемый вид, если настройка была изменена после его создания.
