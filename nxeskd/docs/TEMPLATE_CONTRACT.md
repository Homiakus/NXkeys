# Контракт PRT-шаблона

## Обязательные объекты

| Имя | Назначение |
|---|---|
| `AUTO_BORDER` | Рамка листа |
| `AUTO_TITLE_BLOCK_FORM_1` | Основная надпись |
| `DRAWING_WORK_AREA` | Допустимая область изображений |
| `TITLE_BLOCK_AREA` | Запрещенная зона штампа |

## Рекомендуемые области

```text
CHANGE_TABLE_AREA
TECH_REQUIREMENTS_AREA
PARTS_LIST_AREA
BEND_TABLE_AREA
```

Области можно представить именованными прямоугольниками, точками или объектами с атрибутом `AUTO_REGION_ID`.

## Связанные атрибуты штампа

Рекомендуемый производственный способ — ассоциативные тексты шаблона, связанные с атрибутами детали. Это снижает зависимость от конкретной реализации `EditTitleBlockBuilder`.

## Стили

В шаблоне должны быть заранее настроены:

- шрифт ЕСКД;
- размерные стили;
- линии;
- стрелки;
- штриховка;
- стили геометрических допусков;
- стиль Parts List;
- стиль позиций;
- таблица изменений.

JSON может переопределять доступные параметры, но шаблон остается источником геометрии и сложных Drafting Preferences.
