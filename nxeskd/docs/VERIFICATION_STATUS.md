# Статус верификации NX ESKD Drawing Automation

Дата аудита и обновления: 13.08.2026  
Версия интеграционного пакета: **1.1.0-integrated**

## Четыре канонических статуса верификации

1. **`implemented`**: логика полностью реализована в исходном коде.
2. **`ci_verified`**: логика доказана автоматическими модульными, архитектурными и регрессионными тестами в CI без NX.
3. **`nx_verified`**: логика подтверждена станцией Siemens NX 2512.6000 со всеми лицензиями по протоколу `NX2512_6000_STATION_TESTS.md`.
4. **`target_only`**: функция запланирована в архитектуре, но требует физической NX-станции или дополнительных коммерческих лицензий.

## Архитектурные гарантии интеграции

- Единый launcher NXKeys и единая сессия безопасности (schema 4 / HMAC-SHA256).
- Единая точка входа `CapsLock → E` в Modeling и Drafting (`nxeskd.open_workflow`).
- Запрет модальных ожиданий (`WaitForExit`) в основном потоке NX.
- Изоляция UI: отсутствие WPF/WinForms сборок в NX runtime каталоге.
- Детерминированный конвейер: `ModelSnapshot` → `DrawingPlan` → `Preview` → `Mutation`.
- Раздельные контракты `Generate` (без существующего scope) и `Update` (только при наличии scope).
- Автономный `NxEskd.Core` без ссылок на NXOpen и UI.
